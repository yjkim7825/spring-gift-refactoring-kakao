# 용어 사전

[사용자 스토리](user-stories.md)에 나오는 용어를 정리했다. 영문명은 개발자와 이야기할 때 같은 대상을 가리키는 이름이다.

## 사람과 로그인

| 한글명            | 영문명        | 설명                                                                                                                    |
| ----------------- | ------------- | ----------------------------------------------------------------------------------------------------------------------- |
| 손님              | Guest         | 로그인하지 않은 방문자. 카테고리, 상품, 옵션을 둘러볼 수 있다.                                                          |
| 회원              | Member        | 서비스에 가입한 사용자. 이메일로 구분하고 포인트를 가진다. 이메일로 가입했든 카카오로 가입했든 같은 회원으로 다룬다.    |
| 관리자            | Admin         | 관리자 화면에서 상품과 회원을 운영하는 사람. 지금은 일반 회원과 구분하지 않는다.                                        |
| 회원가입하다      | register      | 이메일과 비밀번호로 회원이 된다. 가입하면 따로 로그인하지 않아도 바로 로그인된다.                                       |
| 로그인하다        | login         | 이메일과 비밀번호로 회원임을 확인받는다. 로그인하고 1시간이 지나면 다시 로그인해야 한다.                                |
| 카카오 로그인하다 | Kakao login   | 카카오 계정으로 로그인한다. 처음이면 자동 가입하고, 이미 가입된 이메일이면 그 회원에 카카오를 연동한다.                 |
| 자동 가입         | auto-register | 카카오 로그인 때 처음 보는 이메일이면 회원을 자동으로 만드는 것. 비밀번호가 없어서 이 회원은 이메일로 로그인할 수 없다. |

## 상품

| 한글명         | 영문명              | 설명                                                                                                                      |
| -------------- | ------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| 카테고리       | Category            | 상품을 묶는 분류. 이름은 겹칠 수 없고, 대표 색상과 이미지가 있다. 예: 식품(초록색)                                        |
| 상품           | Product             | 선물로 주문할 수 있는 품목. 이름, 가격, 이미지가 있고 카테고리 하나에 속한다. 예: 제주 감귤 5kg, 25,000원                 |
| 상품명         | Product Name        | 상품 이름. 공백 포함 최대 15자이고 한글, 영문, 숫자, 공백과 ( ) [ ] + - & / _ 기호만 쓸 수 있다. 예: "[한정] 감귤+한라봉" |
| MD 협의 상품명 | Kakao-reserved Name | "카카오"가 들어간 상품명. 담당 MD와 협의한 경우에만 쓸 수 있다. 예: "카카오 프렌즈 인형"                                  |
| 옵션           | Option              | 상품 안에서 고르는 세부 선택지. 주문과 재고는 옵션 단위로 관리한다. 예: 아이폰 16의 "블루 / 256GB", "블랙 / 512GB"        |
| 옵션명         | Option Name         | 옵션 이름. 공백 포함 최대 50자이고 쓸 수 있는 문자는 상품명과 같다. 한 상품 안에서 겹칠 수 없다.                          |
| 재고           | Stock               | 옵션별로 남은 개수. 주문할 때마다 줄어든다. 한 번에 사는 개수인 "주문 수량"과 다르다.                                     |
| 등록하다       | create              | 관리자가 상품, 옵션, 카테고리, 회원을 새로 만든다.                                                                        |
| 수정하다       | update              | 관리자가 상품, 카테고리, 회원 정보를 바꾼다. 옵션은 수정할 수 없고 추가와 삭제만 할 수 있다.                              |
| 옵션 삭제하다  | delete option       | 상품에서 옵션을 뺀다. 옵션이 하나뿐인 상품에서는 할 수 없다.                                                              |

## 위시와 주문

| 한글명        | 영문명         | 설명                                                                                                  |
| ------------- | -------------- | ----------------------------------------------------------------------------------------------------- |
| 위시          | Wish           | 회원이 관심 상품을 담아 두는 목록의 한 항목. 옵션이 아니라 상품 단위이고, 같은 상품은 한 번만 담긴다. |
| 위시에 담다   | add wish       | 상품을 위시에 추가한다. 이미 담긴 상품이면 기존 항목이 그대로 유지된다.                               |
| 위시에서 빼다 | remove wish    | 내 위시에서 항목을 지운다. 다른 회원의 위시는 지울 수 없다.                                           |
| 주문          | Order          | 회원이 옵션 하나를 골라 포인트로 결제한 기록. 옵션, 주문 수량, 메시지, 주문 일시가 남는다.            |
| 주문 수량     | Order Quantity | 한 번 주문할 때 사는 개수(1개 이상). 이만큼 재고가 줄어든다.                                          |
| 메시지        | Message        | 주문에 붙이는 문구(선택). 카카오 알림 끝에 💌와 함께 나온다. 예: "생일 축하해! 🎉"                    |
| 주문 금액     | Total Price    | 상품 가격 × 주문 수량. 이만큼 포인트가 줄어든다. 예: 25,000원 × 2개 = 50,000원                        |
| 주문하다      | order          | 재고를 빼고, 포인트를 빼고, 주문을 기록하고, 알림을 보내는 과정 전체. "선물하기"와 같은 뜻이다.       |
| 재고 차감     | subtract stock | 주문 수량만큼 옵션 재고를 줄이는 것. 남은 재고보다 많이 주문하면 실패한다.                            |

## 포인트

| 한글명      | 영문명       | 설명                                                                                                               |
| ----------- | ------------ | ------------------------------------------------------------------------------------------------------------------ |
| 포인트      | Point        | 회원이 결제에 쓰는 돈. 1포인트가 1원이고, 새 회원은 0포인트로 시작한다.                                            |
| 포인트 충전 | charge point | 관리자가 회원 포인트를 늘려 주는 것. 1 이상이어야 한다. 회원이 직접 충전할 수는 없다.                              |
| 포인트 차감 | deduct point | 주문할 때 주문 금액만큼 포인트를 줄이는 것. 잔액이 모자라면 "포인트가 부족합니다"라는 안내와 함께 주문이 실패한다. |

## 카카오 연동

| 한글명        | 영문명        | 설명                                                                                                                                 |
| ------------- | ------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| 카카오 연동   | Kakao link    | 회원이 카카오로 한 번 이상 로그인해서 카카오톡 알림을 받을 수 있는 상태.                                                             |
| 카카오 알림   | Kakao Message | 주문을 마치면 카카오톡으로 보내는 주문 요약. 상품명(옵션명), 수량, 금액, 메시지가 들어 있다. 알림이 실패해도 주문은 그대로 성공한다. |
| 나에게 보내기 | send to me    | 카카오 알림을 주문한 회원 자신의 카카오톡으로 보내는 방식. 받는 사람을 따로 정하지 않는다.                                           |
